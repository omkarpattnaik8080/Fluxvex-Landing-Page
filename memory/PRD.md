# Fluxvex — PRD

## Original problem statement
"Build a landing page: completely following the design.md" — Fluxvex, an automated client-reporting platform for digital marketing agencies. Iterated over multiple feedback rounds: (1) light Botwise-style theme per user screenshots, (2) uploaded hero texture image + official Fluxvex icon as logo/favicon, (3) exact-reference sections (features trio, problem diagram, platform + stats), (4) floating pill navbar per Movoice reference, ultra-premium motion illustrations, uniform typography, (5) INR/USD pricing views, (6) pricing NOT disclosed — locked/blurred preview with curiosity effect, (7) backers band (Product Hunt, StartupBase, Meta Tech Partner, AWS Startups, Microsoft Azure Startups, Sarvam), footer office address, premium dark ROI calculator, animated isometric workflow.

## Architecture
- **Frontend**: React 19 (CRA + craco), Tailwind tokens (royal blue #3D43E8 accent, white bg, #F4F2ED warm neutrals, dark #0B0B0D footer), Inter Tight (display/nav/buttons) + Inter (body) + Caveat (sticky note only), framer-motion + lenis + custom `CinematicText` (in-view, once, grapheme-accurate masked line reveal; reduced-motion/no-JS safe).
- **Navbar**: fixed floating pill (rounded-full, warm gray, backdrop blur) over the hero; Sections mega-menu in 3 grouped columns with icon tiles; All Pages directory panel; mobile white sheet with accordions; Escape/outside-click close.
- **Backend**: FastAPI `/api/waitlist` + `/api/contact` — email validation, honeypot, IP rate limit, upsert dedupe, MongoDB persistence; optional Google Sheets sync via `GOOGLE_SHEETS_WEBAPP_URL` env (off per user choice). Pytest suite at backend/tests/test_fluxvex_api.py (12 cases).
- **SEO (production domain https://www.fluxvex.com)**: static head (title/desc/canonical/OG incl. 1200x630 og-image.jpg/Twitter large card), Organization + WebSite + FAQPage JSON-LD kept in lockstep with on-page FAQ text, robots.txt (AI-crawler group + Sitemap line), sitemap.xml (4 routes), llms.txt, per-route titles + canonicals + og:url via `Seo.jsx` (path prop, noindex for 404), favicon + apple-touch-icon = official Fluxvex icon PNG. Noscript content fallback. No fabricated metrics/prices in any metadata surface; pricing appears only as locked masks.
