# Fluxvex — PRD

## Original problem statement
"Build a landing page: completely following the design.md" — Fluxvex, an automated client-reporting platform for digital marketing agencies. Iterated over feedback rounds: (1) light Botwise-style theme per user screenshots, (2) uploaded hero texture + official Fluxvex icon as logo/favicon, (3) exact-reference sections, (4) floating pill navbar, ultra-premium motion, uniform typography, (5) INR/USD pricing views → (6) pricing NOT disclosed — locked/blurred preview with curiosity hook, (7) backers band + footer office address + social channels (LinkedIn/GitHub/YouTube), (8) hero final makeover + GSAP marquees + ONE shared isometric 3D illustration language everywhere, (9) legal pages published as drafts, (10) functional showcase dashboard + light animated calculator.

## Architecture
- **Frontend**: React 19 (CRA + craco), Tailwind tokens (royal blue #3D43E8 accent, white/cream page, #F4F2ED neutrals, dark #0B0B0D footer), Inter Tight (display) + Inter (body), framer-motion + lenis + custom CinematicText headings (in-view, once, grapheme masked-line reveal, reduced-motion/no-JS safe), gsap 3.15 (headline marquee, marquee strip, backers band — core only, hover timeScale slow, reduced-motion static).
- **Iso3D (Three.js, session 9)**: interactive 3D illustrations for HowItWorks, AiComparison ×2, FeatureGrid ×3, Platform, Vision, Showcase layers band — ONE shared WebGL context via drei View (SceneCanvas lazily mounted in Home.jsx ONLY; other routes render 0 canvases), scenes registry components/three/scenes.jsx, DOM-driven tilt/drag/hover/click, reduced-motion static, SVG IsoKit compositions kept as fallbacks.
- **Illustration language (one system)**: shared iso kit `components/iso/IsoKit.jsx` (IsoPlane/IsoTile/IsoWire/IsoBillboard — 3D planes, dashed wires + traveling packets, counter-rotated floating billboards) used by HowItWorks, AiComparison, FeatureGrid, Platform, Consistency; hairline line-art kit `components/hairline/Illustrations.jsx` (Hub/Cabinet/Riffle/Slow/Padlock) for platform accordion minis, security vault, calculator decoration; hairline corner ticks on the hero dashboard.
- **Navbar**: fixed floating pill (rounded-full, warm gray, backdrop blur); Sections mega-menu (3 grouped columns) + All Pages panel; mobile sheet; Escape/outside-click close.
- **Backend**: FastAPI `/api/waitlist` + `/api/contact` — validation, honeypot, IP rate limit, upsert dedupe, MongoDB; optional Google Sheets sync via GOOGLE_SHEETS_WEBAPP_URL (off per user choice). Pytest: backend/tests/test_fluxvex_api.py (13 cases).
- **SEO (production domain https://www.fluxvex.com)**: static head (title/desc/canonical/OG 1200x630 og-image.jpg/Twitter large card), Organization (sameAs: LinkedIn/GitHub/YouTube) + WebSite + FAQPage JSON-LD locked to on-page FAQ text, robots.txt (AI-crawler group + Sitemap), sitemap.xml (17 routes: 4 pages + /blog + 12 posts), llms.txt, per-route canonical/og:url via Seo.jsx (noindex for drafts/404), BlogPosting JSON-LD per post, favicon = official icon. No fabricated metrics/prices in any metadata surface.
- **Navbar dropdown (perf)**: desktop panels always mounted, toggled via opacity/transform/visibility transitions (compositor-only, will-change-transform); hover close-grace timer (160 ms) on the whole navbar container — no mount/unmount flicker, no translate(-50%) jump (menu-pop keyframes fixed to translateY only, still used by mobile sheet).
